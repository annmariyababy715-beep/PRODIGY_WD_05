# Weather App 

A simple and responsive Weather App built using HTML, CSS, and JavaScript.  
This application allows users to search for weather information by entering a city name.

## Features

- Search weather by city name
- Displays:
  - Temperature
  - Weather condition
  - Humidity
  - Wind speed
  - Location name
- Responsive and user-friendly interface
- Real-time weather data using WeatherAPI

## Technologies Used

- HTML
- CSS
- JavaScript
- WeatherAPI

## API Used

WeatherAPI  
https://www.weatherapi.com/

## How to Run

1. Download or clone the repository
2. Open the project folder in VS Code
3. Add your API key inside `script.js`

```javascript
const apiKey = "YOUR_API_KEY";
```

4. Run `index.html` using Live Server
